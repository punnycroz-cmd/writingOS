## 2. CORE COMPONENTS & INTERFACES

### 1. State Graph & Epistemic Layers
* Distinguishes `WORLD_FACT`, `CHARACTER_PERCEPTION`, `CHARACTER_INTERPRETATION`, and `NARRATIVE_ASSERTION`.
* Protects information ownership via 5 distinct stances: `KNOWS`, `SUSPECTS`, `BELIEVES`, `MISREMEMBERS`, and `DOES_NOT_KNOW`.

### 2. Cognitive Directives Generation Engine (Fiction Pack)
* Executes the 6-stage causal pipeline: Somatic State $\to$ Sensory Attention Filter $\to$ Cognitive Interpretation $\to$ Emotional Response $\to$ Intentional Goal $\to$ Action/Dialogue Cadence.

### 3. Decoupled Dual-Track Validation & Surgical Repair
* **Track 1 (Integrity Gate):** Strict zero-contradiction validation against Canon.
* **Track 2 (Quality Gate):** Continuous domain rubric scoring.
* **Targeted Region-Scoped Repair:** Fixes defective paragraphs in place without collateral degradation to valid surrounding prose.

### 4. HandoffRouter & State Concurrency
* Enforces Article IV (Safe Abstention): Terminates oscillation cycles and asks structured user clarifications under ambiguity.
* Optimistic Concurrency Control (OCC): Automatically invalidates stale generation plans upon user mid-session mind-changes.
